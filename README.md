# Sistema de Controle de Estoque 📦

Este é um projeto desenvolvido para fins de estudo com o objetivo de construir uma aplicação web simples e funcional para **gerenciamento e controle de estoque**. A aplicação conta com todas as operações fundamentais de um **CRUD** (Create, Read, Update, Delete).

## 🎯 Objetivos do Projeto

* 📌 **Prática de Desenvolvimento Web:** Aplicar conceitos do ecossistema Python na construção de aplicações web.
* 🛠️ **Implementação de CRUD:** Criar rotas e rotinas para cadastro, listagem, edição e remoção de produtos no estoque.
* 🎨 **Interface Amigável:** Utilizar Bootstrap para garantir uma interface responsiva, simples e intuitiva.

## 🛠️ Tecnologias Utilizadas

* **Back-end:** [Python 3.x](https://www.python.org/)
* **Framework Web:** [Flask](https://flask.palletsprojects.com/)
* **Front-end:** HTML5, CSS3, [Bootstrap 5](https://getbootstrap.com/)
* **Banco de Dados:** SQLite *(ou adicione o banco de dados utilizado)*

## ⚙️ Funcionalidades (CRUD)

- [x] **Create:** Cadastrar novos produtos no estoque (nome, quantidade, preço, categoria, etc.).
- [x] **Read:** Visualizar a lista completa de produtos armazenados e seus detalhes.
- [x] **Update:** Atualizar dados de produtos existentes (alterar quantidade, ajustar preços, etc.).
- [x] **Delete:** Remover produtos do sistema.
